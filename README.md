# Prabhaa Hotels - Official Brand & Properties Portal

A luxury, modern, responsive hospitality web application built for **Prabhaa Hotels** in Chittoor, Andhra Pradesh, showcasing two premier properties:
1. **Prabhaa Grand Inn** (Flagship Luxury Hotel at M.S.R Circle, Rajiv Gandhi Road)
2. **Prabaa Royal Park** (Business Class & 100% Pure Veg Hotel at Church Street)

---

## 🌟 Key Features

- **Unified Luxury Brand Architecture**: Central brand showcase featuring both hotels with property switchers, live contact routing, and high-contrast ivory/gold white aesthetic.
- **Dedicated Hotel Experiences**: Deep-dive pages for Grand Inn and Royal Park detailing room configurations, tariffs, transit connectivity, and amenities.
- **Culinary Showcase**:
  - *Grand Inn*: Annapurna Pure Veg, Amaravathi Non-Veg (Andhra spices & Biryanis), and upcoming Touch Bar lounge.
  - *Royal Park*: 100% Pure Veg dining with 350+ delicacies, pure ghee sweets & savouries counter, and outdoor catering.
- **Grand Banquets & Convention Halls**: Darbar Function Hall & The Royal Hall with interactive enquiry handling.
- **Property Photo Galleries & Lightbox**: HD imagery of rooms, restaurants, and event spaces with property filtering.
- **Direct Reservation & Contact System**: Instant front desk telephone links (`tel:`), direct WhatsApp messaging, and interactive forms.

---

## 🚀 Tech Stack

- **React 18** with **Vite**
- **Tailwind CSS v4** (`@tailwindcss/postcss`)
- **Lucide React** icons
- **React Router** for seamless property routing

---

## 🛠️ Getting Started

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
